# IELTS Pro - Homepage

A modern and responsive homepage for a fictional IELTS Institute built with **React JS**.

## 🚀 Features
- Responsive Navbar with logo & links  
- Hero section with headline, sub-text, CTA button, and banner image  
- Feature cards (Speaking Practice, Mock Tests, AI Band Score, Expert Mentors)  
- Student Testimonials section  
- Footer with quick links & contact info  

## 🛠️ Tech Stack
- React JS  
- CSS (custom)  


## ▶️ Run Locally
```bash
# clone repo
git clone https://github.com/your-username/ielts-pro-homepage.git
cd ielts-pro-homepage

# install dependencies
npm install

# start dev server
npm start
